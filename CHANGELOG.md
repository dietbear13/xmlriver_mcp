# Changelog

## 0.2.0 — 2026-11-09

- Параллельный сбор позиций и регионов, до 9 одновременных запросов.
- Новый MCP-инструмент `batch` для списков SERP и Wordstat без ручного создания файлов.
- Команда `xmlriver batch` с сохранением результатов, кэшем и продолжением после остановки.
- Общая пауза при перегрузке, снижение параллельности и постепенное восстановление скорости.
- Учёт Retry-After и времени блокировки; раздельные счётчики попыток для параллельных заданий.
- Ограничение бюджета, сохранение частичных результатов и корректная отмена всех работников.
- Немедленный журнал с fsync для попыток и полученных страниц, хранение больших ответов на диске.
- Продолжение со следующей сохранённой страницы и команда восстановления отчёта после аварийного завершения.
- Автоматическое сохранение результатов MCP-инструмента `batch`.

## 0.1.1 — 2026-11-08

- Переписана инструкция для работы из чата: фразы можно передать сообщением без ручного создания CSV и YAML.
- Объяснены автоматические действия помощника, пакетный сбор и сохранение результатов.
- Разделены первое подключение и работа с уже установленным пакетом.
- Описано хранение ключей в настройках MCP и текущее поведение `.env`.
- Поведение API, MCP и CLI не изменилось.

## 0.1.0 — 2026-11-08

- Independent async client, four MCP tools and CLI.
- Shared rate limiting, strict arguments, safe errors and bounded retries.
- Unified pagination, versioned cache, atomic storage and CSV backups.
